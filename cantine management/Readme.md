About 
The rapid growth of e-commerce platforms has resulted in a large volume of customer 
reviews being generated daily. These reviews contain valuable information about product quality, 
usability, and customer satisfaction, but manually analyzing such a massive amount of textual data 
is difficult and time-consuming. Sentiment analysis, a technique in Natural Language Processing 
(NLP), helps determine whether customer feedback expresses positive, negative, or neutral 
opinions. This project focuses on developing an intelligent sentiment analysis system for analyzing 
customer reviews using machine learning techniques. The system utilizes a dataset containing more 
than 200,000 product reviews collected from an e-commerce platform, including attributes such as 
product name, rating, review title, summary, and sentiment label. Initially, the textual data 
undergoes preprocessing steps such as converting text to lowercase, removing punctuation, 
eliminating numbers, removing stop words, tokenization, and lemmatization to reduce noise and 
improve data quality. After preprocessing, the text is transformed into numerical form using the TF
IDF (Term Frequency–Inverse Document Frequency) vectorization technique, which assigns 
importance to words based on their frequency and relevance. The dataset is divided into training 
and testing sets to evaluate model performance using metrics such as accuracy, precision, recall, and 
F1-score. Additionally, a web-based interface is developed using the Flask framework, allowing 
users to input product reviews and receive sentiment predictions in real time. The proposed system 
helps businesses automatically analyze customer opinions, identify satisfaction levels, detect 
negative feedback, and improve product offerings. By integrating Natural Language Processing, 
machine learning, and web application deployment, the system provides an efficient solution for 
automated sentiment classification. The project demonstrates how intelligent text analysis can 
support decision making and enhance customer experience by extracting meaningful insights from 
large-scale textual data.
